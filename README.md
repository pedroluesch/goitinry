# Site do Itinry (www.goitinry.com)

Site estático de apresentação. O app fica em outro repositório e é publicado em app.goitinry.com.

- `index.html`: página principal (português no HTML, inglês em `app.js`)
- `privacidade.html` e `termos.html`: modelos, revise com um advogado e preencha os campos entre colchetes
- `app.js`: troca de idioma e o endereço do Instagram (`INSTAGRAM_URL`)
- `og.png`: imagem que aparece ao compartilhar o link
